Python-Skript zum Kennzeichnen doppelter Immich-Videos. Dieses Python-Skript verbindet sich mit der Immich-API, um doppelte Videos zu kennzeichnen. Es identifiziert insbesondere .MP4-Dateien, die von Google Fotos erstellt wurden, zusammen mit Bewegungsfotos (.jpg-Dateien mit demselben Dateinamen). Das Skript ruft alle Assets ab, findet die Videoduplikate, erstellt gegebenenfalls ein Tag „Doppeltes Video aus Google Fotos“ und weist die gefundenen Videos damit zu.
